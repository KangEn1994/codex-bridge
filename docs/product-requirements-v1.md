# Codex Bridge v1 产品需求基线

确认日期：2026-08-10

## 产品定位

Codex Bridge 是 Windows Codex Desktop 的手机远程控制面，不是远程桌面。产品由 Windows Host、HTTPS/WSS Relay 与 Android APK（PWA 备用）组成。手机通过 Bridge 配对，不重复登录 OpenAI/Codex。

## 首批信息架构

- 首页：电脑连接状态、运行中任务、待处理审批/失败/队列、最近任务和继续任务。
- 当前任务：真实 Codex 历史与实时输出、继续对话、审批、停止和任务级队列管理。
- 工作区：Windows 文件夹及其任务；支持远程目录选择和从工作区创建任务。

## 关键规则

- 工作区等同于 Windows 文件夹；每个任务绑定一个工作区，一个工作区可以包含多个任务。
- 多个工作区可并行工作；“当前任务”仅表示手机当前查看的任务。
- 浏览其他工作区不会中断任务。同一工作区并发写入暂不禁止，但需要风险提示。
- Codex 空闲时立即发送；同一任务正在执行时消息进入独立持久化队列，支持查看、编辑、取消和排序，当前轮结束后自动发送。
- 不设置工作区目录白名单；v1 不做终端、完整文件管理、多电脑、多用户、Git Worktree 或复杂自动化。

## 对话显示

- 最终回答优先，以安全的 GFM Markdown 渲染。
- 过程更新、命令、工具调用、思考摘要与文件操作合并为可折叠活动区。
- 代码块支持语言/文件名、语法高亮、折叠、自动换行、全屏和复制。
- Diff 支持文件分组、增删标识、复制 Diff/修改后代码/文件路径。
- 命令、路径、日志、单条消息与整段回答均可复制；成功反馈 0.5 秒自动消失。
- 实时输出保持稳定，不在用户阅读旧内容时强制滚到底部。

## 工作区选择

- 远程列出 Windows 磁盘、桌面、文档、下载、用户目录和最近工作区。
- 支持逐级浏览、面包屑、返回上级、文件夹搜索和选择当前文件夹。
- 只显示文件夹；电脑离线时仅显示已知的最近工作区。

## 配对与 Android

- App 内置扫码。首次启动扫码后自动写入 Relay 地址与凭证并进入首页。
- 配对二维码使用短期一次性凭证；设置保留重新扫码与手动地址兜底。
- APK 提供原生剪贴板兜底，正确处理系统安全区，不在状态栏叠加原生悬浮按钮。
- 前台实时更新；重要通知仅包含完成、待批准、失败和电脑离线。

## 视觉方向

- 首页采用“值守首页”方向，当前任务采用“对话接手”方向。
- 深色石墨背景、荧光黄绿色主操作、绿色在线状态；48dp 最小触控范围。
- 底部主导航为：首页 / 当前任务 / 工作区。设置与通知放二级入口。
