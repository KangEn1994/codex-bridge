# Code of Conduct

We want Codex Bridge to be a welcoming, practical, and respectful open-source project.

Participants are expected to:

- communicate respectfully and assume good faith;
- welcome people with different backgrounds and experience levels;
- focus criticism on ideas and code rather than individuals;
- avoid harassment, discrimination, threats, doxxing, or publication of private data;
- respect security embargoes and responsible disclosure requests.

Maintainers may edit or remove contributions and restrict participation when behavior threatens the safety, privacy, or health of the community. Report conduct concerns privately to the maintainers through their GitHub profiles. Maintainers will handle reports confidentially to the extent practical.
